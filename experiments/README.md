# LoRA experiments

These scripts and `fl_nodes/lora_trainer.py` are experimental development code. The trainer is not registered as a ComfyUI node. Full training and inference quality have not been validated for this release.

Supply your own local audio and sidecars under `experiments/data/`, or run `create_test_data.py` to create synthetic test audio. Review script settings and model paths before running; no recordings or model weights are bundled.
